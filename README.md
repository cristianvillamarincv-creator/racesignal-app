# RaceSignal

Expo / React Native iOS app (with a Supabase backend) for endurance athletes: bring race history together and ask Signal what it means.

- `mobile/`: the app. Start with `mobile/README.md`.
- `supabase/`: schema migrations and Edge Functions. See `supabase/README.md`.
- `docs/development-workflow.md`: branches, Expo-first testing, release process, backend safety.
- `docs/handoffs/`: point-in-time technical handoffs.
- `docs/legal/`: privacy policy, terms, support text, App Store metadata draft.
- `B1_ARCHITECTURE.md`, `B0_FINDINGS.md`: historical milestone records.

Release 1.0.0 (build 18) is preserved at tag `v1.0.0-build18`; next-version work happens on `release-1.1`.
